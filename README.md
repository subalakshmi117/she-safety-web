# 🛡️ Safety Web

A modern web application designed to promote online safety and help users access useful safety-related information and resources.

## 📌 About the Project

Safety Web is a React-based web application created to provide users with a simple and user-friendly platform for safety awareness.

The project focuses on presenting safety information through a clean and responsive interface.

## ✨ Features

- 🛡️ Safety-focused web interface
- 📱 Responsive design
- ⚡ Fast and modern UI using React + Vite
- 🧭 Easy navigation
- 🎨 Clean and user-friendly design
- 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Git & GitHub
